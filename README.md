# ☕ Coffee Sales Interactive Dashboard

This project is an **interactive sales analytics dashboard** designed to track **coffee sales performance, revenue trends, and product-wise insights**. It helps businesses make **data-driven decisions** using visual analytics.

---

## 🎯 Dashboard Objectives

* Monitor overall sales performance
* Track daily, monthly, and yearly revenue
* Identify **top-selling coffee products**
* Analyze **customer purchase behavior**
* Compare sales across categories and time

---

## 📊 Key Dashboard Features

* ✅ Total Sales, Revenue & Quantity KPIs
* ✅ Product-wise & Category-wise Sales Analysis
* ✅ Monthly & Daily Sales Trends
* ✅ Revenue Contribution Breakdown
* ✅ Clean, interactive, and user-friendly visuals

---

## 🛠️ Tools Used

Excel / Power BI | Data Visualization | Pivot Charts | Slicers

---

## 🎯 Use Cases

Retail Analytics | Sales Tracking | Business Intelligence | Portfolio Dashboard
